A standalone, responsive portfolio website tailored for junior social media / digital content applications.

- Responsive single-page website

## Publish for free
### GitHub Pages
1. Create a public repository.
2. Upload all files in this folder.
3. GitHub → Settings → Pages → Deploy from branch → `main` → `/ (root)`.
4. Use the generated `github.io` URL on the CV.

### Netlify
1. Create a Netlify account.
2. Use the manual deploy / drag-and-drop upload option.
3. Upload this whole folder.
4. Use the generated URL on the CV.

Do not add social links, client names, testimonials or results unless they are genuine and belong to you.
